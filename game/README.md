# 实战篇 · 用 RxJS 做一个接星星游戏

双击本目录的 [play.html](play.html)，点「开始游戏」。轻点方向键换一轨，按住连续移动。接住一颗得 1 分，漏掉三颗就结束。页面已包含 RxJS 7.8.2，可以离线玩。默认打开完整游戏；第一节用的是右上角的「移动接收器」。

在控制台里，日志到达和点击导出是两件独立的事。到了游戏里也一样：按键要立即移动接收器，落星要等下一拍。两种动作共用同一个轨道位置，一次压线移动能不能得分，就取决于它们谁先发生。

| 小节 | 打开游戏时选择 | 这一关发生了什么 |
|---|---|---|
| [一 · 让接收器动起来](01-input.md) | 移动接收器 | 两次落星之间轻点，接收器仍会走一步 |
| [二 · 接住第一颗星](02-collision.md) | 第一颗星 | 星到落点的前一刻还能换轨 |
| [三 · 让一局游戏成立](03-round.md) | 完整一局 | 画面和计分牌看见同一颗随机生成的星 |
| [四 · 暂停、继续、再来一局](04-lifetime.md) | 暂停与重开 | 暂停留住场上的星，重开时清空 |
| [五 · 用虚拟时间验收](05-time.md) | 固定轨道验收 | 第三次漏接的那一拍，时钟就停 |

### 读代码和跑实验

[game.ts](game.ts) 定义一拍的规则和整局的流。[main.ts](main.ts) 把浏览器事件接进来，并把状态画出来。五关共用这两个文件，通过关卡选择逐项开放规则。每节的实验都能在浏览器里观察，涉及精确时间的结论还可以在 [game.test.ts](game.test.ts) 复核。

修改源码时，使用课程现有的 Node.js 24+ 环境和依赖。在**项目根目录**运行：

```sh
node --test game/game.test.ts
node_modules/.bin/tsc -p game
node game/build.mjs
```

第三条命令用项目已有的 esbuild 将源码与 RxJS 打包进 play.html。刷新已打开的游戏即可看到修改。只想玩或阅读时，直接打开成品即可。
