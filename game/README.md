# 实战篇 · 用 RxJS 做一个接星星游戏

双击本目录的 [play.html](play.html)，点「开始游戏」。轻点方向键滑动一轨，按住连续换轨，松手结束连移。每颗星值 1 分，漏掉三颗结算。页面已包含 RxJS 7.8.2，可离线打开。首次打开是第四关的完整游戏，按阅读顺序学习时，请从右上角选择第一关。

建议接在第 18 章后阅读。读完这篇，你应该能回答三个问题：谁有权推进游戏一拍？两个面板各订阅一次，会启动几个时钟？暂停和重开分别要撤掉哪一层订阅？

| 小节 | 打开游戏时选择 | 动手验收 |
|---|---|---|
| [一 · 让接收器动起来](01-input.md) | 移动接收器 | 写出按下、按住、松手对应的位置序列 |
| [二 · 接住第一颗星](02-collision.md) | 第一颗星 | 预测压线移动会不会得分 |
| [三 · 让一局游戏成立](03-round.md) | 完整一局 | 验证计分牌和画面共用一次执行 |
| [四 · 暂停、继续、再来一局](04-lifetime.md) | 暂停与重开 | 证明暂停保留生成进度，重开清空进度 |
| [五 · 用虚拟时间验收](05-time.md) | 固定轨道验收 | 手算一局，查出结算退订发生在哪一拍 |

### 读代码和跑实验

[game.ts](game.ts) 定义一拍的规则和整局的流。[main.ts](main.ts) 把浏览器事件接进来，并把状态画出来。五关共用这两个文件，通过关卡选择逐项开放规则。每节的实验都能在浏览器里观察，涉及精确时间的结论还可以在 [game.test.ts](game.test.ts) 复核。

修改源码时，使用课程现有的 Node.js 24+ 环境和依赖。在**项目根目录**运行：

```sh
node --test game/game.test.ts
node_modules/.bin/tsc -p game
node game/build.mjs
```

第三条命令用项目已有的 esbuild 将源码与 RxJS 打包进 play.html。刷新已打开的游戏即可看到修改。只想玩或阅读时，直接打开成品即可。
