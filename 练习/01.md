## 发散题 A｜唱片店里的播客试听席

每位听者从片头开始试听。唱针每走一格，播放器尝试读一格，依次是雨声、旁白、片尾标记。遇到片尾才盖章，遇到坏片亮红灯，摘耳机就归还这次借的声道。

甲听一格就摘耳机。再空拨一格，乙来听完整张。谁听到什么？空拨时还会读盘吗？把乙的第二格换成坏片，再数总读取、盖章和归还次数。如果唱片只有片尾、按键还没返回机器就认出了它，声道最后归谁？

<details>
<summary>参考解法与实验</summary>

甲只听到雨声，摘耳机不盖章。摘下时从驱动表移走甲的声道，所以空拨一格，读盘数仍为 1。乙重新从片头听雨声、旁白，再读到片尾标记才盖章。总计四次读取，两次借出、两次归还，每次离席后活动声道都是零。

```ts
reads++
const groove = record[at++]
if (groove === '片尾') sink.complete()
else if (groove === '损坏') sink.error(Error('坏片'))
else sink.next(groove)
```

把乙第二格换成坏片，乙听到雨声后亮红灯，最后一拍空拨，总读取降到三次。只有片尾的唱片会在打开过程中立刻完成；随后交回的清理函数被加到已关闭的订阅上，立即归还。收据只有章，再拨一格也没有声音或新的读取。

[实验源码](../labs/transfer/01.ts)。在项目根目录运行 `node labs/transfer/01.ts A`。

</details>

## 发散题 B｜双指作画时，把哪一笔交给印章机

红笔、蓝笔落下时各借一张草片，移动添点，抬笔才压印并还片。失去触点就丢弃草图。合上画板会取消它手里的每一笔；已经交给印章机的笔可以继续画。每张片只还一次。

第 0 拍红落在 2，1 拍蓝落在 8，2 拍红移到 3，3 拍把红交给印章机，4 拍合板。之后 5 拍蓝移到 9，6 拍红移到 5，7 拍红抬起，8 拍红再移到 6。最后由谁印下了哪几个点？在交接后、合板后、抬笔后各看一次，谁手里还有草片？若机器已关，交接失败，红笔仍归画板，结果又怎样？

<details>
<summary>参考解法与实验</summary>

第三拍把红笔交给印章机时，红片上已有 [2,3]，蓝片上只有 [8]。交接只换能关闭它的器材，红笔用的仍是原订阅，已有的点也还在。实验的交接发生在一个同步调用内。

```ts
if (pen.closed || press.closed) return false
holder.remove(pen)
press.add(pen)
holder = press
```

交接后有红、蓝两张片在外；第四拍合板只退蓝片，蓝笔的 9 写不进去。第六拍红再添 5，抬笔时印下「印章机 红 2 3 5」并退片，最后一片也不欠。压印应写在抬笔处理里，归还写在清理里，否则合板也会印出一个蓝点。

目标已关，检查会返回 false，红笔仍归画板，两片随合板一起退回。若只做 add，忘了 remove，画板还保有关闭红笔的权力；用「合板后手里还剩哪张片」就能抓住这个错误。

[实验源码](../labs/transfer/01.ts)。在项目根目录运行 `node labs/transfer/01.ts B`。

</details>

## 发散题 C｜暗房冲印中途缺了一只夹子

暗房依次借罩、灯、夹。缺件就停，借齐才可按快门拍一张。收工时按借用的反序拆卸；即使灯插头卡住报错，也要继续归还其他器具。

试三次：借到罩后缺灯；借齐后拍照；借齐后撤景、还灯时卡住。每次按什么顺序还，最后欠哪件，有几张相片？第三次谁会收到「灯未退回」？再撤一次景，哪些操作还会执行？

<details>
<summary>参考解法与实验</summary>

缺灯时只借到罩，归还尝试只有罩，没有相片也没有欠件。为覆盖这条中途失败的路径，在借第一件之前就登记收工函数，随后每借成一件就追加到 borrowed。

```ts
sink.add(() => {
  const failures: Error[] = []
  for (const item of borrowed.reverse()) {
    attempts.push(item)
    if (item === jammed) failures.push(Error(item + '未退回'))
    else held.delete(item)
  }
  if (failures.length) throw new UnsubscriptionError(failures)
})
```

顺利曝光时三件都曾借出，按夹、灯、罩的次序归还，得到一张相片。撤景时同样尝试退这三件，卡住的灯留在 held，罩仍须归还，学员手上没有相片。管理员可在调用 unsubscribe 的地方从 UnsubscriptionError 取到失败原因。再次撤景不会重跑订阅的清理；那盏灯仍须单独维修。

[实验源码](../labs/transfer/01.ts)。在项目根目录运行 `node labs/transfer/01.ts C`。

</details>
