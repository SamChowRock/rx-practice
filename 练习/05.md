## 发散题 A｜鼓点到来时，灯究竟有多亮？

舞台灯的目标亮度从 50 起步。每转一次手轮就按位移调整，立即限在 0 到 100 之间，多出的位移作废。鼓响才把最新目标发给灯具；从上次鼓响起没有碰过手轮，这一拍就不发。位移为 0 也算碰过。

第 1、3、7 格分别转 +40、+30、−20，第 14、17 格转 −90、+10，第 25 格轻触（0）。鼓点在 10、20、30、40 格，42 格收台。试着在每次动作旁记下目标亮度，再只圈出真正送给灯具的指令。每拍只取最后一次位移，或先求和再限位，哪一拍会出错？如果换成直接报当前亮度的推杆呢？

<details>
<summary>参考解法与实验</summary>

手轮的每一个输入都是位移。目标从 50 依次变成 90、100、80、0、10、10。第三格溢出的 20 已经作废，所以第七格从 100 往回走到 80。

```ts
const clamp = (n: number) => Math.max(0, Math.min(100, n));
const move = (level: number, delta: number) => clamp(level + delta);
const level = wheel.pipe(scan(move, 50));
```

把算出的目标接到 sample(beat)，得到第 10 格的 80、第 20 格的 10、第 30 格的 10。零位移也触发了一次调整；40 格鼓响前没再碰过手轮，没有指令。先取样再累计，第一拍只剩 −20，从 50 起算就误发 30；把位移相加到拍末再限位，第一拍又会误发 100。如果设备换成直接报绝对亮度的推杆，每拍只留最新读数就足以给舞台下令。

[实验源码](../labs/transfer/05.ts)。在项目根目录运行 `npm run transfer -- 05`。

</details>

## 发散题 B｜听鸟人何时能给一句鸣唱画句号？

听鸟鸣时，每一声都记一个孔。距末声满五格而没有新声才确认一句。录音里依次是 2 低、4 低、8 高、16 高、23 低。到 32 格收纸，能记下几句？每句各写首声、末声、声数、确认时刻。连续两声同音仍是两声。

第二遍在 26 格摘掉耳机。确认册里还能留下哪些句子？另一本速记允许收下半句，但要标「截断」，它会多记什么？试用一段短录音说明只抄最后一声会漏掉什么。若录音开始前鸟就可能在唱，怎样标注第一句才不至于把缺失的开头当作安静？

<details>
<summary>参考解法与实验</summary>

2 格低先约在 7 确认。4 格的低把期限推到 9，8 格的高再推到 13。13 是交纸时间；末声实际发生在 8。每一声都放进当前组，静默确认时取出整组。只记防抖发出的最后一声，会把这一组三声记成一声。

```ts
const calls = heard.pipe(timestamp(clock), map(({ value, timestamp }) =>
  ({ at: timestamp, pitch: value })));
const silence = calls.pipe(debounceTime(5, clock));
```

完整记录按（首，末，声数，交纸时刻）为 (2,8,3,13)、(16,16,1,21)、(23,23,1,28)。26 撤耳机时，确认册只有前两句；速记本加上 (23,23,1,26)，注明截断。收集器后退订会丢掉未确认的组；给它的输入一个正常完成，则会交出手里剩下的那组。

再试第 1、3 格两声同音，8 格确认一次，孔数应为二。若开始观察前就已在鸣叫，首句标「左端未观测」；没有开始以前的静默记录，就无法声称已听到整句。

[实验源码](../labs/transfer/05.ts)。在项目根目录运行 `npm run transfer -- 05`。

</details>
