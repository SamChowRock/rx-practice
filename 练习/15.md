## 发散题 A｜合唱排练室的三间音舱

三间音舱起初全空，声部按到场顺序领舱。等到队首所需的舱同时空齐才能开练，后来的不能绕过它。开练后占到唱完；有人归还或退出候场，立即重新分配。

| 到场 | 声部 | 需要几间 | 开练后持续多久 |
|---:|---|---:|---:|
| 0 | 女低 alto | 2 | 5 |
| 1 | 男低 bass | 2 | 2 |
| 2 | 独唱 solo | 1 | 1 |
| 3 | 男高 tenor | 2 | 3 |

画出候场和占舱区间，标出每次分配后还空几间。若男低在第 4 分钟退出候场，谁能提前开练？为什么只数正在唱的组数会高估剩余舱位？

<details>
<summary>把舱牌摆在桌上，一次转移对应一次开练</summary>

原安排如下。男低从 1 等到 5，即使独唱只需一间，也得排在他后面。

| 声部 | 候场 | 占舱 |
|---|---|---|
| 女低 | 无 | [0,5) 用 2 间 |
| 男低 | [1,5) | [5,7) 用 2 间 |
| 独唱 | [2,5) | [5,6) 用 1 间 |
| 男高 | [3,7) | [7,10) 用 2 间 |

5 分钟时男低与独唱同时开练，只开两组却占满三间。归还舱和收到撤队消息时，都要重新看队首是否能开练。男低在 4 退出时没领过舱，无舱可还；女低还占两间，剩的一间正好给独唱。男高从 5 练到 8。

```ts
const index = waiting.findIndex(group => group.name === 'bass');
assert.ok(index >= 0);
waiting.splice(index, 1);
seat();  // 立刻拿现在的空舱数重新排
```

如果漏掉 seat()，独唱要等到 5 有人归还才开练，最终人人都唱完了，开练时间却错了。

</details>

## 发散题 B｜桌面排版师的三条字位刻线

排标题 ABA。使用两把尺，同款的 A、B 各量一次，耗时分别为 4、1 拍。字宽以半点为单位，普通款 A、B 宽 7、5，宽款宽 9、6。无字距调整，印完每个字的刻线取**从行首累计**的点数，四舍五入，遇半进一。

从 0 拍量普通款。三条刻线各在哪，何时可交付？若在第 2 拍改量宽款，旧测量可取消，不能沿用旧款字宽；第 3 拍关闭选款，当前标题继续排完。哪些测量完成了，最后的刻线是什么？比较逐字取整与累计后取整，再找一组末尾对而中途错的刻线。

<details>
<summary>从两把尺的读数，恢复三个字的前缀长度</summary>

| 标题 | 使用的推进量（半点） | 连续笔尖位置（半点） | 换成点 | 印纸刻线（点） |
|---|---|---|---|---|
| 普通 ABA | 7、5、7 | 7、12、19 | 3.5、6、9.5 | 4、6、10 |
| 宽款 ABA | 9、6、9 | 9、15、24 | 4.5、7.5、12 | 5、8、12 |

同一款只需量 A、B 各一次，却要沿原字序 ABA 取三次宽度。每份测量带回字与宽度，先返回的 B 就不会占了第一个 A 的位置。

逐字先取整再相加，普通款会把宽度写成 4、3、4，得到 4、7、11。第二条刻线已经多一点。整行很长时，每遇一个半点都可能向同一方向漂移。若只印最后一个记号，把普通 ABA 错排为 BAA，最终总宽仍为 19 个半点，前两条刻线却分别为 3 和 6，第一条错了。验收要保留三条刻线各自的位置，并用未取整的累计量参与下一次计算。生产上怎么对齐像素还涉及显示比例，这里“半点→整点”的固定规则让误差能用整数直接验算。

```ts
// entries 是这一款各字测量所得的 [字, 半点宽度]。
const table = new Map(entries);
let advance = 0;
const stops = word.map(glyph => Math.round((advance += table.get(glyph)!) / 2));
```

**换款的第 2 拍发生了什么？** 普通款 B 已经量到 5，普通款 A 的四拍还差两拍。换款意味着两把尺和中间那张表都交给新底片；即使款式名只换一个字，旧 B 也不能给新 B 凑数。第 2 拍开启宽 A 和宽 B，第 3 拍宽 B 返回 6，第 6 拍宽 A 返回 9。接着把三条刻线交给印纸员。一条收集全部字宽的链要放在每次款式选定的内部，才能使两份中间表自然彼此隔开。

```ts
const proof = compose(true);
assert.deepEqual(proof.measured, ['romanB@1','wideB@3','wideA@6']);
assert.deepEqual(proof.pages, ['wide:5/8/12@6']);
```

第 3 拍收起的是款式选择板。实验安排 `faces.complete()`，表示再没有新款进入。当前正在量的宽 A 仍需到第 6 拍才完成，组合后的结果会等它交出。若印纸员此刻退订整条组合，相当于收走尺子和底片，随后不会有第 6 拍的交付。设计关闭按钮时应明确要的是哪一种动作。固定的输入带已经能区分它们，同样是第 3 拍以后没有新选择，底片数组分别有一项与零项。不要把“两把尺已经动过”作为交付证据。

</details>
