# 11｜一次失败应当结束哪段工作

<a id="transfer-a"></a>

## 发散题 A｜一页诗集该等字等到什么时候？

每次翻页后最多等五拍选字体。期限内有可排字的专用字就选它，否则用设备上的本地字。两套字都能排本诗集。每页只定一次版，不许事后换字。全场只许取一次专用字体，两页的字号、粗细和字集相同。

第 0 拍开第一页并开始取字，3 拍收到部分字节，8 拍解码就绪，9 拍取字完成，10 拍翻第二页。写下各页何时定版、用哪套字、之后还能否改变，再标出第一页已定版而取字仍在继续的区间。

把就绪改为第 4 拍，其余时刻不变，重新判断两页的选择。用一次不必安装字体的排练说明怎样区分“收到字节”和“可以排字”。

<details>
<summary>展开排字单、虚拟排练与错误接法</summary>

第 0 拍打开第一页，并启动两件事：本页等字，排字间取字。第 5 拍本页必须定版，但排字间还在为下一页取字；这两份工作有不同的截止时间。

第 3 拍只有部分字节，不能据此排字。第 5 拍选本地字并固定版面。第 8 拍字形就绪，第 9 拍读取结束，第 10 拍翻页即可选专用字。

实验中的 face 表示可以排字，local 表示改用本地字。

```ts
const ready = data.pipe(
  filter(value => value === 'face'),
  shareReplay({ bufferSize: 1, refCount: true })
);
const choose = () => ready.pipe(timeout({ first: 5, with: () => of('local') }), take(1));
const owner = ready.subscribe();
```

owner 在第 0 拍就订阅，并一直持有到取字完成。第一页第 5 拍超时后不再监听，所以第 8 拍不会跳版；第二页第 10 拍能立即读到已就绪的字形。把字形提早到第 4 拍，只有第一页改为第 4 拍定专用字。排练时分别报告“收到字节”和“可以排字”，只数真正定版的次数。

</details>

## 发散题 B｜缺了一块拱片，拼图工坊还能检哪一道接缝？

拱片、轮片、边片同时开始测量，彼此独立，每件只检一次。拱片和边片都通过才能试拼桥洞；轮片和边片都通过才能给出齿数之和。所有工位结束后交一张合并单，局部失败仍应保留独立工位的结果，零齿算有效测量。

0 拍开工，2 拍拱片轮廓纸撕裂，报告无法测量并结束。轮片在 4 拍量得 3 齿，5 拍收工；边片在 6 拍量得 2 齿，7 拍收工。不能补检。写出合并单的交付时刻、两项结论和各检具的占用区间。

把两个试拼分别连到它所需的木片上。若换成边片损坏，哪些结论会变？若轮片测到零齿呢？设计一条记录，区分尚在测量和被其他工位的错误提前取消。

<details>
<summary>展开试拼判定、失败对照与依赖推导</summary>

桥洞依赖拱片和边片，齿轮花纹依赖轮片和边片。拱片无法测量时，花纹的两份输入仍然可得。若错误直接传到 forkJoin，另外两份订阅也会在第 2 拍被拆掉。

把失败处理移到各自的 inspect 函数里，每个工位交一张结果卡。量出零齿是成功，有数值 0；检具坏了就交出带部件名的失败卡。

```ts
type Piece = 'arch' | 'wheel' | 'rim';
type Result = { ok: true; teeth: number } | { ok: false; piece: Piece };
```

```ts
function inspect(piece: Piece, source: Observable<number>) {
  return defer(() => {
    starts.push(piece)
    return source.pipe(
      map((teeth): Result => ({ ok: true, teeth })),
      catchError(() => of<Result>({ ok: false, piece }))
    )
  })
}
```

```ts
const verdict = forkJoin({
  arch: inspect('arch', arch), wheel: inspect('wheel', wheel), rim: inspect('rim', rim)
}).pipe(map(({ arch, wheel, rim }) => ({
  bridge: arch.ok && rim.ok ? '可试拼' : '待补片',
  gear: wheel.ok && rim.ok ? wheel.teeth + rim.teeth : '待补片'
})));
```

拱片在 2 结束，轮片在 5 结束，边片在 7 结束，此时交一张单，桥洞待补，花纹有五齿。若边片损坏，两项都待补；轮片实测零齿则花纹还有两齿。记录每个工位的订阅与清理时刻：若拱片在 2 报错就使其他两份订阅也在 2 清理，轮片与边片已经被提前赶下台。

</details>
