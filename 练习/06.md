## 发散题 A｜纸图翻过山脊，绘笔该追哪一幅？

离线地图用两支笔给瓦片着色，每支一次画一格，领笔才开始计时。按清单顺序开工，画完一格就贴上它自己的位置。换图时撤掉旧纸，释放旧图的笔并丢弃等候项。两幅图没有共用瓦片。

第 0 刻夹入西幅，要画脊、谷、桥，耗时分别为 12、4、6 刻。第 7 刻换东幅，要画湾、岸，分别耗时 3、5 刻。第 8 刻收起图册，允许画完当前图。写下领笔、还笔和观众看到各格的时刻。

若每幅各用两支笔，或要等西幅画完才能开东幅，哪条记录会不同？把换图提前到第 2 刻，比较脊、谷、桥留下的领笔和盖印记录。

<details>
<summary>查看换图前后的领笔和归还记录</summary>

| 时刻 | 纸框 | 两支笔在做什么 | 此刻观众新见的印记 |
| --- | --- | --- | --- |
| 0 | 西幅 | 脊与谷 | 无 |
| 4 | 西幅 | 谷交笔，桥接手；脊继续 | 谷 |
| 7 | 东幅 | 脊、桥交还，湾、岸接手 | 无 |
| 8 | 东幅 | 老师收册，两笔继续 | 无 |
| 10 | 东幅 | 湾交笔，岸继续 | 湾 |
| 12 | 东幅 | 岸交笔，结束 | 岸 |

变式的第 2 格换纸时，谷还差两格，脊还差十格，两笔都在旧图上，桥一直等在队里。桥条目存在于西幅清单，没人取笔，暂停或取消“桥的计时器”就无从谈起。脊、谷则都有领用、早退还书面记录，但都未盖印。再将时刻改回 7，谷会同时有领用、正常盖印、归还三项，脊只有领用和早退还，三种状态现在有了可执行的判别。只看上图的最终截图无从知道桥在主例中也消耗过三格的工时。

```ts
const raster = (cell: Cell) => defer(() => {
  starts.push([clock.now(), cell.id]);
  peak = Math.max(peak, ++active);
  return timer(cell.cost, clock).pipe(map(() => cell.id), finalize(() => {
    active--;
    frees.push([clock.now(), cell.id]);
  }));
});
```

```ts
const render = (cells: Cell[]) => from(cells).pipe(mergeMap(raster, 2));
sheets.pipe(switchMap(render))
  .subscribe(id => inks.push([clock.now(), id]));
```

换成外层并发，7 格时两幅各占两支笔，峰值变四；串行则要等西幅在 12 格画完，东幅的湾到 15 才出现。

## 发散题 B｜踏板已经松开，录音机为什么还在采鼓声？

甲、乙、丙三只踏板共用一个现场话筒。设备空闲时踩下即可录音，忙时新踩的一脚作废。只有本段主人松脚才封袋。现场声音不能回放。

踩下与松开的时刻分别为甲 0、9，乙 3、5，丙 12、18。话筒在 1、6、10、14 刻依次收到咚、哒、嗒、啪。19 刻停止接收新申请，21 刻撤台。写出每只录音袋的主人、开口和剪断时刻、收进去的音节，并标出无人录下的声音。

若每一脚都排队，或任何人松脚都能剪断，分别从哪一刻起与正确记录不同？若换成点一下就从头播到尾的预录鼓样，排队会怎样影响播放顺序和内容？

<details>
<summary>展开录音袋、踏板门控与迟到的剪带信号</summary>

把四声鼓点分别放进下面三个踏板的时间记录。第 10 格的“嗒”没有落入任何录音，现场话筒无法补发。

| 袋名 | 实际开口 | 标记过的声音 | 剪断时刻 |
| --- | ---: | --- | ---: |
| 甲 | 0 | 1 咚，6 哒 | 9 |
| 乙 | 没有开袋 | 无 | 无 |
| 丙 | 12 | 14 啪 | 18 |

乙从没开袋，这和开了袋但碰巧没人敲鼓不同。只数录到的声音，两种情况都是零；领用和归还的记录能分开它们。

先独立写“已获准录音的一脚”要做什么。press.take 是这一次获准使用的踏板名。mic 在任意时刻都可发声；录音订阅一装上才听得见此后的声音。up 是全教室的松脚广播，先判断报的名字与本段是否一致，再只要第一次匹配。通知流送出一次匹配值时，takeUntil 结束本段录音。名字不符的松开不会让这份订阅提前结束。

```ts
const capture = (press: Press) => defer(() => {
  opened.push([clock.now(), press.take]);
  return mic.pipe(
    takeUntil(up.pipe(filter(key => key === press.take), take(1))),
    map(sound => press.take + '/' + sound),
    finalize(() => cuts.push(clock.now() + '/' + press.take)),
  );
});
```

用 `down.pipe(exhaustMap(capture))` 启动录音。若改成排队，第 3 格接纳乙时没有监听松脚，第 9 格才为乙开袋。第 5 格的松乙早已过去，连第 14 格的啪也被错装进乙袋。若去掉松脚信号里的名字判断，第一次错剪在第 5 格，甲会漏掉第 6 格的“哒”。若只要点播预录音频，晚开仍能从头播放同一份素材，按点击顺序串行就合适。

</details>
