## 发散题 A｜山谷定向赛，裁判什么时候可以盖完赛章？

红、蓝两人各自依次经过松、石、桥才算完赛；遇到不符合下一站的记录就跳过。现场时钟已对齐，同一人不在同刻经过两站，卡号唯一。卡可以乱序送达和重传。裁判收到封签 n 后，才能认定现场时刻 ≤ n 的新卡已齐，并按现场先后签章。之后首次收到这个范围内的新卡要隔离，已见副本忽略；旧或重复的封签不再生效。

| 送到桌面的次序 | 卡和封签，@ 后是现场时刻 |
|---|---|
| 1–5 | 红桥 R3@30，红松 R1@10，R1 副本，蓝松 B1@15，封签 19 |
| 6–10 | 红石 R2@20，封签 29，封签 30，R2 副本，蓝石 BL@18（首次送达） |
| 11–15 | 蓝石 B2@32，蓝桥 B3@33，封签 33，旧封签 31，封签 33 副本 |

红、蓝各在哪次封签时拿章？R2 副本和 BL 为何处理不同？若只存完赛名单，中途交班会丢哪些信息？再算一次取消对时保证的情况。

<details>
<summary>定向赛讲评：先决定谁能宣布过去已经结束</summary>

封签 19 时，红、蓝都只确认了松。红桥卡虽然先到，刻度 30 还在签线之后。封签 29 时红又确认了石；到 30 才能用桥卡给红盖章。R2 副本早就收过，直接丢弃；BL 的刻度 18 已经封签却是首次见到，放进隔离区。蓝随后凭 32、33 的两张卡在封签 33 时完赛。最后两枚旧封签都不能再盖章。

```ts
if (event.type === 'punch') {
  if (punches.has(event.card) || quarantine.includes(event.card)) return;
  if (event.at <= through) { quarantine.push(event.card); return; }
  punches.set(event.card, event);
  return;
}
```

收到封签时，只处理刻度在 through 以内的记录，按现场时间排列，并分别维护每人的路线进度。若直接按送达顺序走，红的桥排在松之前，红会缺最后一站。若排序后不检查 through，红又会在 29 提早盖章。

交班时除了已盖的章，还需知道最后封到了哪、每个人确认到了哪、有哪些卡待处理、哪些卡号已见过、哪些卡已隔离。若设备时间无法比较，就要由赛事方给出每位选手可比较的经过次序，才能继续按路线自动判定。

</details>

## 发散题 B｜逐格皮影，两张一模一样的底片要不要算两帧？

摄影台初始为 0 度、亮灯、空胶片。旋钮只改姿态，踩踏板才拍一格，每格记角度与灯光。撤销剪去最后一格，恢复放回最近剪去的一格。试摆保留恢复资格，新曝光才作废旧分支。导演按取片才保存当前胶片的独立副本。

1. 空胶片上剪一次。摆到 10 度暗灯，连拍两格，再摆到 20 度亮灯，拍一格。
2. 连剪两次，恢复一次；试摆到 40 度暗灯，先不拍。此时的木偶、末帧、下一张可恢复的底片各是什么？
3. 拍一格，再按恢复。剪去末帧后让导演取片，再恢复末帧。导演的副本与摄影台上的胶片各有哪些帧？

找两段末帧一样、下一次剪辑结果却不同的历史。

<details>
<summary>摄影台讲评：把输入的姿势、不可替代的动作与可恢复状态分开</summary>

姿态可以反复变化，每次踏板只取当下的姿态。连续踩两次，即便姿态完全相同，也要拍成两张独立的底片。

```ts
const rig = new BehaviorSubject<Pose>({ arm: 0, light: '明' });
const shutter = new Subject<void>();
const cuts = new Subject<Edit>();
const exposures = shutter.pipe(
  withLatestFrom(rig),
  map(([, pose]): Edit => ({ type: 'expose', pose }))
).subscribe(event => cuts.next(event));
```

用 past 依放映顺序保存现有底片，future 的第一项是下次可恢复的底片。空胶片上剪辑保留原状。两次曝光 10 后再拍 20，得到 [10,10,20]。连剪两次后，past 为 [10]，future 为 [10,20]；恢复一次，past 为 [10,10]，下一张可恢复的是 20。

```ts
if (event.type === 'undo') {
  return film.past.length
    ? { past: film.past.slice(0, -1), future: [film.past.at(-1)!, ...film.future] }
    : film;
}
return film.future.length
  ? { past: [...film.past, film.future[0]], future: film.future.slice(1) }
  : film;
```

摆成 40 度本身不会改胶片。若直接按恢复，会得到 [10,10,20]；若先踏一下拍下 40，就进入新分支 [10,10,40]，future 清空，此时恢复键已没有底片可取。另作一个只看胶片的对照：[10,40] 与 [20,40] 的最后一帧都显示 40，剪一次却分别露出 10 和 20。最后剪掉 40 时取片，导演拿到 [10,10] 的副本，恢复后的摄影台是 [10,10,40]。

</details>
