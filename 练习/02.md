## 发散题 A｜把魔术师的一副牌分给两桌

四张牌从顶到底是 ABCD。按位置 3、2、1 的顺序，把该位置的牌与纸带指定位置的牌交换（下标从 0 起）。早课纸带为 1、0、1，晚课从 ABCD 重新开始，用 0、0、0。每课只洗一次。

东桌只看早课顶牌，西桌稍后翻早课整副牌。两桌和晚课各看到了什么，用了几条纸带？如果改成同桌轮流从顶上**拿走**一张，每人又会拿到什么？试让纸带在位置 2 给出越界的 3：这一局必须作废，在哪一步才能放心开始发牌？

<details>
<summary>参考解法与实验</summary>

早课按纸带依次把 ABCD 换成 ADCB、CDAB、CDAB。教练开场时洗一次，桌子随后各自遍历同一个数组。

```ts
const openRound = () => from(shuffle(tapes[used++]))
const morning = openRound()
const east = read(morning.pipe(take(1)))
const west = read(morning)
```

东只翻 C，西读 CDAB，这时只用掉一条纸带。晚课从原始 ABCD 用第二条纸带洗成 BCDA。同桌轮流抽牌则由一个发牌员依次推进 CDAB，东得 CA，西得 DB。两人若各自重新订阅一遍，都会先拿到 C。

位置 2 时允许交换的下标仅有 0、1、2，读到 3 便作废。在私有副本洗完并验证成功后才开始发牌，才能保证错误出现前无人看过一张局部结果。

[实验源码](../labs/transfer/02.ts)。在项目根目录运行 `node labs/transfer/02.ts A`。

</details>

## 发散题 B｜朗读课上，谁说完才轮到下一位

语音盒读完「小 船」才读「靠 岸」。开始一个词和整句收尾是两种回调。每次开读返回一张只能停本句的票，空句可能在返回票之前就结束。

第 0 拍开读，1、2 拍听到小、船，4 拍第一句收尾，5 拍听到靠，6 拍停课。7、8 拍有人拿旧票报告岸和句尾。哪些词会亮起，第二句哪拍启动，最后还占着几张票？再试「空句、到」，看看开读函数刚返回时哪一句还占着盒子。若第一句在送出船后报错，整场停演，第二句还会启动吗？

<details>
<summary>参考解法与实验</summary>

第 2 拍「船」开始发音时第一位还占着盒子。直到第 4 拍收住，才允许第二句启动。把每句适配成一个源，词到达发 next，句尾发 complete；外层 concat 等这次 complete 才订阅下一句。

```ts
const ticket = box.start(line, {
  word: word => sink.next(word),
  end: () => sink.complete(),
  fail: reason => sink.error(reason),
})
return () => box.stop(ticket)
```

第 1、2、5 拍听到小、船、靠。第 6 拍停课撤票，没有谢幕，也没有有效票，后来的岸与句尾都无效。空句在 start 返回前就结束；它的清理只停自己的票。开课函数返回时两句都启动过，只剩第 2 票有效，还没听到词。「到」和句尾随后各来一次，才可谢幕。第一句听到船后若报错，整场只启动过第一句，回收票，留下小、船和故障记录。

[实验源码](../labs/transfer/02.ts)。在项目根目录运行 `node labs/transfer/02.ts B`。

</details>

## 发散题 C｜排字铺的字模纸带

排字机每拍收到一截 UTF-8 字节。换行就交一盘，空行也交。LF 和 CRLF 都算换行，独立的 CR 算正文。正常卷尾才交尚未换行的末盘；坏编码要报错，已交的盘保留。

四截字节依次是 `E6 9C`、`88 0D`、`0A 0A 73`、`65 61`，第 5 拍卷尾。`E6 9C 88` 表示「月」，0D 和 0A 是 CR 和 LF，后三个字母拼作 sea。哪一拍能交哪一盘？第 2 拍后停机，或者在首盘以后读到半个汉字就遇卷尾，又各能交什么？再把轮子调成每拍只送一个字节，诗和交盘时刻各有何变化？

<details>
<summary>参考解法与实验</summary>

第一截只有「月」的头两个字节。让同一个解码器活过整个读取，才有机会在第二截补齐它。第二截结尾的 CR 还得留着等下一字符。

```ts
const decoder = new TextDecoder('utf-8', { fatal: true })
// 每到一截，在同一台 decoder 上继续
accept(decoder.decode(chunk, { stream: true }))
```

把解出的字符追加到本行缓存。每遇 LF 就切一行，紧靠这个 LF 的末尾 CR 去掉；允许切出空串。第 3 拍得到「月」和空行，尾部留下 s；第 4 拍补成 sea，第 5 拍卷尾用无参 decode() 检查残字，成功才交末盘 sea。

第 2 拍停机时还没见到 LF，也没有卷尾，因此零盘、无错。若第一盘后收到半个汉字就到卷尾，fatal 解码器报错，已交的月保留。改成逐字节喂，月在第 5 个字节交，空盘在第 6 个，sea 仍在卷尾。实验枚举九个字节间的 256 种切法，盘内文字必须一致。

[实验源码](../labs/transfer/02.ts)。在项目根目录运行 `node labs/transfer/02.ts C`。

</details>
