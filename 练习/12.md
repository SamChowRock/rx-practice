## 发散题 A｜给一小节和弦配动画

五个音头编号 0–4，依次在 0、3、3、6、10 拍起音，同拍的两个音都要响。投影仅在 2、5、9、13 拍更新，每幅图显示从上一次更新到现在的新音头，包括开场。

各幅图有哪些编号？若撤掉第 5 拍的画面，声音与后续画面各会怎样变？想一种画面对了、音却晚了的接法。

<details>
<summary>展开排练记录与参考推导</summary>

乐手的记录应是 0 拍弹 0，3 拍同时弹 1 和 2，6 拍弹 3，10 拍弹 4。若把发音放在绘制回调，首音就会被推到 2 拍。绘制只需取走自上次画面后新增的音头，按下一个未画音头的下标 next 读谱。

```ts
animationFrames().pipe(take(frames.length)).subscribe(({ elapsed }) => {
  const crossed: number[] = [];
  while (next < onsets.length && onsets[next] <= elapsed) crossed.push(next++);
  pictures.push([elapsed, ...crossed]);
});
```

四幅画依次含 [0]、[1,2]、[3]、[4]。撤去时刻 5 的画面，时刻 9 会一次领走 [1,2,3]，起音时间仍依原谱。

</details>

## 发散题 B｜裁判桌上的双向沙漏

白黑各有五格沙，白先走。每单位时间，行棋方的一格沙流给对手；按钟换方。一方流空立即落旗，同刻按钟也不能挽救。第一盘在 2、6、8 按钟，第二盘在 5、7 按钟。

算出两盘每次换方时的余沙和落旗时刻。如果最后没人按键、显示屏也没刷新，由谁触发落旗？

<details>
<summary>展开裁判演算与无人按钟试验</summary>

每次先按上一手经过的时间转移余沙，再决定能否换方。第一盘交接记录依次是 (2,3,7,黑)、(6,7,3,白)、(8,5,5,黑)。黑方随后无人按键，必须在 13 自行落旗，白十黑零。第二盘白在 5 已经流空，当时按钟也得判终局；7 的按键无效。

```ts
alarm.unsubscribe();
settle();
if (!ended) active = active === '白' ? '黑' : '白';
history.push([last, white, black, ended ? '终局' : active]);
if (!ended) alarm = clock.schedule(expire, active === '白' ? white : black);
```

settle 按时钟结算当前行棋者，用完余沙就标记 ended。每次有效按钟先撤旧预约，换方后按对方的剩余量预约下一次落旗。让屏幕整盘不刷新，仍应在 13 和 5 分别记下终局。

</details>

## 发散题 C｜面团能进下一道工序了吗

教学配方规定，温度连续五个时间单位处于 [24,27] 时响一次铃。开始温度未知，温度计只报变化，两次报告之间沿用前值。时刻 1、3、5、7、9 依次报 25、26、29、24、27，随后保持不变。本题没有读数与铃声同刻的冲突。

哪次预约的铃声应取消，最后何时响？若每两格换一次合格温度，能否仍然按时放行？

<details>
<summary>展开连续时间演算与实验改法</summary>

时刻 1 进入合格范围，候选铃在 6。3 虽然从 25 变成 26，仍然合格。5 越界，撤铃。7 再次进入，原定 12 的铃一直有效，9 的 27 仍属合格。

```ts
const eligible = readings.pipe(map(t => t >= 24 && t <= 27));
const hold = (inside: boolean) => inside ? timer(5) : NEVER;
const ready = eligible.pipe(distinctUntilChanged(), switchMap(hold), take(1));
```

若 1、3、5、7 分别报 24、25、26、27，连续合格从 1 开始，6 就该响。比较原始温度会一再重置计时。先比较合格与否，只有跨过边界才让 switchMap 换掉计时器。

</details>
