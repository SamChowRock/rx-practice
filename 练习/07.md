## 发散题 A｜给默片排一场可以倒带的双语放映

默片有三段字幕，含起点、不含终点。0–2 秒“门开 / OPEN”，2–5 秒“进来 / ENTER”，7–9 秒“请坐 / SIT”，空档显示“熄”。两份清样都已就绪，初始语言为中文。

排练第 1 至 8 刻依次为：报片内 0 秒、报 2 秒、换英文、报 5 秒、报 8 秒、倒回 1 秒、换中文、报 2 秒。放映员每次报位置才交一张提示；校对员在位置或语言变化时都交一张，首次报位置前不交。分别写出时刻、片内秒数和提示。再给一个能让只往前找字幕的实现出错的输入。

中文稿按段号 1、2、3 到达，英文稿按 2、1、3 到达。说明该怎样把报位对应到字幕、把两份译稿对应到同一段。

<details>
<summary>展开两条纸带、倒带推导与双语清样的验收办法</summary>

| 排练刻 | 更新后的片内位置 | 实际放映的新增提示 | 静帧校对的新增提示 |
|---|---:|---|---|
| 1 | 0 | 门开 | 门开 |
| 2 | 2 | 进来 | 进来 |
| 3 | 2 | — | ENTER |
| 4 | 5 | 熄 | 熄 |
| 5 | 8 | SIT | SIT |
| 6 | 1 | OPEN | OPEN |
| 7 | 1 | — | 门开 |
| 8 | 2 | 进来 | 进来 |


第 4 刻虽然没有对白，仍要交一张“熄”，否则上一句会留在银幕上。textAt 每次从清样中找满足 `start <= p && p < end` 的段，查不到便返回“熄”。倒回第 1 秒也按同一个条件查，所以能从 SIT 回到 OPEN。

```ts
position$.pipe(withLatestFrom(language$), map(([p, l]) => textAt(p, l)))
  .subscribe(word => projected.push([tick, word]))
combineLatest([position$, language$]).pipe(map(([p, l]) => textAt(p, l)))
  .subscribe(word => proof.push([tick, word]))
```

译稿要按段号装配。按抵达位置配对会得到中 1 英 2、中 2 英 1、中 3 英 3；按段号合起来，第 2 段先凑齐。

</details>

## 发散题 B｜两台秤怎样配出一份可复烤的面团

台面有粉、水两台净重秤，起初均无读数。任一秤更新，指针按“水重 ÷ 粉重 × 100%”重算；粉重为零时显示“待投粉”。每只盆另有封盆踏板，踩下就确认该盆最后一次读数，两盆都封好才填一张配方卡。

第 1 至 8 刻依次为粉 0、水 120、粉 200、水 130、封水、粉 250、封粉、取走水盆后秤报 0，单位为克。写下各刻的指针和首次能填卡的时刻、克数、比例。若未称水就踩踏板，该给操作员和拿卡的人什么反馈？

换一道称量任务：秤依次报累计重量 0、80、125，换空盆归零，随后报 30。请还原每一铲的份量，说明换盆时如何更新计算起点。

<details>
<summary>展开秤盘推导、封盆协议与累计读数的换算</summary>

| 排练刻 | 秤或踏板 | 台面指针本刻交付 | 已确认的盆 |
|---|---|---|---|
| 1 | 面粉 0 | 尚无水读数，无交付 | 无 |
| 2 | 水 120 | 待投粉 | 无 |
| 3 | 粉 200 | 60% | 无 |
| 4 | 水 130 | 65% | 无 |
| 5 | 封水 | 无新读数 | 水 130 |
| 6 | 粉 250 | 52% | 水 130 |
| 7 | 封粉 | 无新读数 | 水 130、粉 250 |
| 8 | 水 0 | 0% | 两只封盆仍为上行克数 |


```ts
function seal(pedal$: Subject<void>, scale$: Subject<number>) {
  return pedal$.pipe(withLatestFrom(scale$), map(([, grams]) => grams), take(1))
}
forkJoin({ flour: seal(flourPedal$, flour$), water: seal(waterPedal$, water$) })
  .subscribe(card => cards.push(card))
```

让合卡订阅在开练前就位。若没称过水就踩踏板，withLatestFrom 取不到水重，take(1) 还在等；应提示重踩。第 7 刻两盆都已确认，卡上粉 250、水 130，含水率 52%。第 8 刻的零只改变指针。累计重量做差时，以换盆并去皮作为新的零点，三铲依次是 80、45、30 克。

</details>
