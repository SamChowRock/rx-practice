## 发散题 A｜从舞垫触点认出换脚步

舞垫反复报告左脚或右脚是压着还是松着。一次真实落脚要从松变压。相邻两次落脚若左右互换、相差一拍或两拍，就画一支箭头。休止线会截断箭头，但人的脚仍压在原处。每拍最多一个动作，没收到消息的拍也要计时。

记录是 0 左压，1 左压，2 右压，3 左松，4 左压，5 休止，6 右压，7 右松，8 右压，9 左松，11 左压，12 右松，13 右压。先留下真正落脚的拍，再连箭头。换一小段「0 左压、1 左松、2 左压、3 右压」，最后应从哪次左压开始连？

<details>
<summary>参考解法与实验</summary>

先给左右脚各记一个「是否压住」。松脚虽然不交出舞步，仍得更新这个状态，否则看不见下一次同脚落地。划休止线时脚并没有抬起来，因此第 6 拍右压只是持续读数。真正落脚的是 L0、R2、L4、R8、L11、R13。

```ts
const arrows = steps.pipe(pairwise(), filter(([a, b]) =>
  a.kind === 'foot' && b.kind === 'foot' &&
  a.foot !== b.foot && b.beat - a.beat <= 2
), map(([a, b]) => [a.beat, b.beat]))
```

把休止线也留在步骤序列中，pairwise 就会产生「脚、线」和「线、脚」，自然没有跨线的一对。两步需异脚、拍距至多二，箭头为 0→2、2→4、11→13。短谱两次左压都是真正落地，L2 接替 L0 成为 R3 的邻居，故画 2→3。

[实验源码](../labs/transfer/03.ts)。在项目根目录运行 `node labs/transfer/03.ts A`。

</details>

## 发散题 B｜词典里的两个 café 和一个 cafe

词典按语种、词目、义项三项判断重复，保留先收的稿件和它的原始拼写。忽略大小写；法语 é 与 e 加组合尖音符视为同一字，重音要保留。土耳其语里 İ 配 i，I 配 ı。

按次序收七张卡，括号里是义项号：

1. 法语 Café（1），饮品
2. 法语 Cafe 后接 U+0301（1），重复投稿
3. 法语 CAFÉ（2），店铺
4. 法语 cafe（3），代号
5. 英语 cafe（1），小馆
6. 土耳其语 İL（1），省
7. 土耳其语 IL（2），字形样例

哪几张能装订？分别查法语 café、法语 cafe、土耳其语 il、英语 cafe，会找到哪些卡？一位读者打不出重音，也希望得到提示。可以改哪部分，让他找到 Café 而仍然保留精确检索？

<details>
<summary>参考解法与实验</summary>

把词目统一成 NFC，再按卡片语言转小写，最后再做 NFC。法语两种有重音写法得到同一键，没重音的 cafe 仍不同。给装订键加上语种和义项号，才能同时留下两个义项及跨语种同形词。

```ts
map(card => ({ card, key: spelling(card.lang, card.word) })),
distinct(({ card, key }) => JSON.stringify([card.lang, key, card.sense]))
```

校样保留 1、3、4、5、6、7 的原稿。依题目查询顺序，法语 café 得 1、3，法语 cafe 得 4，土耳其语 il 得 6，英语 cafe 得 5。提示可另外建在查询层，只在无重音法语查询时折叠重音，对不同于精确结果的候选词头各提示一次。cafe 的主结果仍为 4，建议 Café 一项，点入才显示两种释义。

[实验源码](../labs/transfer/03.ts)。在项目根目录运行 `node labs/transfer/03.ts B`。

</details>

## 发散题 C｜给接力赛制作终点成绩条

接力赛按净用时排名。依冲线次序交来青 12049、黄 11980、白 12049、紫 11970、橙 12051，单位都是毫秒。黄队犯规。同一净用时并列，后面的名次跳过并列人数；同分者按交卡顺序印。

给观众排一次榜：显示时间四舍五入到十分之一秒，另列与前一支有效队的毫秒差，榜首留空。哪两队看上去一样快，名次却不同？再取消紫队资格，谁排第一，哪项分差消失？第一张卡来时就能宣布冠军吗？

<details>
<summary>参考解法与实验</summary>

先筛犯规卡，再按原始毫秒排序，精确同分沿用交卡先后。若先算相邻差再删黄，青前面会残留一道与无效成绩计算出来的差。

```ts
const gap = previous === undefined ? null : card.ms - previous
if (gap !== 0) rank = i + 1
previous = card.ms
const display = (Math.round(card.ms / 100) / 10).toFixed(1)
```

| 队 | 名次 | 大屏（秒） | 与前队差（毫秒） |
|---|---:|---:|---:|
| 紫 | 1 | 12.0 | — |
| 青 | 2 | 12.0 | 79 |
| 白 | 2 | 12.0 | 0 |
| 橙 | 4 | 12.1 | 2 |

青比紫慢 79 毫秒，大屏同为 12.0，仍分属两名。再剔除紫，青、白并列第一，橙第三，分差依次为空、0、2。第一张卡到时还不知道后面谁用时更短；所有有效成绩到齐、资格确定，才能公布这张最终成绩条。

[实验源码](../labs/transfer/03.ts)。在项目根目录运行 `node labs/transfer/03.ts C`。

</details>
